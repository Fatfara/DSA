What is Maximum Subarray Sum?

Kadane’s Algorithm is a classic dynamic programming algorithm used to solve the maximum subarray problem. The goal is to find a contiguous subarray (elements right next to each other) within a one-dimensional array of numbers that yields the largest possible sum.

💡 Core Idea: Instead of checking every single combination, Kadane’s algorithm scans through the array once. It maintains a running sum and resets it if it drops below zero, making it extremely fast with O(N) time complexity!
Approach 1

The Brute Force Approach

A naive way to solve this is to generate all possible subarrays using nested loops, calculate each sum, and keep track of the maximum.

  1. Initialize globalSum = 0 to keep track of the best sum.
  2. Use a loop starting at index i and an inner loop starting at index j to form subarrays.
  3. Sum up the numbers and update globalSum if a higher sum is found.

Java Implementation

private static int findMaximumSubArraySumUsingBruteForce(int[] arr) {
    int globalSum = 0;
    for (int i = 0; i < arr.length; i++) {
        int localSum = 0;
        for (int j = i; j < arr.length; j++) {
            localSum = localSum + arr[j];
            globalSum = Math.max(globalSum, localSum);
        }
    }
    return globalSum;
}
Time: O(N²) Space: O(1)
Approach 2 (Optimal)

Kadane’s Algorithm

Instead of nested loops, Kadane's algorithm updates two main variables as it iterates across the array:

  • • sum: Tracks the current running subarray sum. If sum drops below zero, we reset it to 0 because negative numbers only drag down future sums.
  • • maxSum: Stores the maximum sum encountered so far.

Java Code Implementation

package org.example.Array.Day8;

public class MaximumSubArraySum {
    public static void main(String[] args) {
        int[] arr = {10, 20, -40, 60, -50, 60};
        long max = findMaximumSubArraySumUsingKadaneAlgorithm(arr);
        System.out.println(max); // Output: 70
    }

    private static long findMaximumSubArraySumUsingKadaneAlgorithm(int[] arr) {
        long sum = 0;
        long maxSum = Long.MIN_VALUE;
        for (int i = 0; i < arr.length; i++) {
            sum = sum + arr[i];
            maxSum = Math.max(sum, maxSum);
            if (sum < 0) {
                sum = 0;
            }
        }
        if (maxSum < 0) {
            maxSum = 0;
        }
        return maxSum;
    }
}
Time Complexity: O(N) Space Complexity: O(1)
