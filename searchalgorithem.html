Array Interview Patterns & Decision Guide

Master the mental frameworks used by top software engineers to identify and solve array problems instantly.

1. Two Pointer Technique

When to use: Sorted arrays, finding pairs/triplets, reversing elements, palindromes, or comparing elements from both ends towards the center.

int left = 0, right = arr.length - 1;
while (left < right) {
  if (condition) left++;
  else right--;
}

2. Sliding Window Technique

When to use: Subarray or substring problems asking for max/min sum, longest substring with K distinct characters, or smallest subarray meeting a threshold.

int windowSum = 0, left = 0;
for (int right = 0; right < arr.length; right++) {
  windowSum += arr[right];
  while (windowSum > target) windowSum -= arr[left++];
}

3. Prefix Sum Technique

When to use: Fast range sum queries or finding subarrays whose sum equals K. Reduces O(N^2) brute force to O(N) using cumulative sums and HashMaps.

int[] prefix = new int[n];
prefix[0] = arr[0];
for(int i=1; i<n; i++) prefix[i] = prefix[i-1] + arr[i];

4. Kadane's Algorithm

When to use: Finding the maximum subarray sum in a 1D numeric array in linear O(N) time without checking all N^2 combinations.

int maxSoFar = arr[0], currMax = arr[0];
for (int i = 1; i < arr.length; i++) {
  currMax = Math.max(arr[i], currMax + arr[i]);
  maxSoFar = Math.max(maxSoFar, currMax);
}
